# CadFlow v0.5.0

CadFlow v0.5.0 is a local deterministic workflow release that prepares the
project for optional LLM providers without enabling provider calls by default.

## Release Position

This release is LLM-ready, not LLM-dependent:

- No cloud service, account system, database, or authentication layer is added.
- No LLM provider SDK, API key, network call, or token transcript is required.
- `DeterministicAgentAdapter` remains the only default adapter.
- The source of truth remains file-based run artifacts.

## Highlights

- Added a narrow `AgentAdapter` boundary for structured requirement parsing,
  planning drafts, repair suggestions, and review explanations.
- Routed Requirement and Planning stage drafts through the local deterministic
  adapter while preserving validation gates.
- Added assumption-aware workflow decisions:
  - `proceed_with_assumptions`
  - `ask_user`
  - `return_to_requirement`
  - `return_to_planning`
  - `revise_existing_model`
- Allows low-risk L0 drafts to proceed with explicit recorded assumptions.
- Exposes compact Web Console metadata for:
  - assumptions
  - missing fields
  - follow-up requests
  - requirement flow decisions
  - planning flow gates
  - gate-decision payload summaries
  - sanitized adapter activity
- Keeps gate decisions and runtime stage history auditable in `logs/runtime.json`.

## Artifact Contract

The stable source-of-truth artifacts for this release are:

- `prompt.txt`
- `requirement.json`
- `planning_artifact.json`
- `input_ir.json`
- `report.json`
- `report.md`
- `agent_trace.json`
- `logs/runtime.json`

Public Web Console metadata is path-free and avoids raw secret-like content.
Raw artifacts remain readable for local audit.

## Non-Goals

v0.5.0 does not implement:

- real LLM provider calls
- arbitrary LLM-generated CAD code execution
- full revision execution
- cloud deployment
- multi-user auth
- browser-native CAD editing
- production engineering sign-off

- an optional JSON-contract LLM adapter scaffold with fake-client tests and
