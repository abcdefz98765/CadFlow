# Feature Library

Common feature intents:

- through hole
- counterbore
- countersink
- slot
- fillet/chamfer
- rib
- boss
- standoff
- wire exit
- cable strain relief
- snap tab
- hinge pin
- gasket groove

Feature knowledge describes reusable design intent before it becomes
backend-specific CAD operations. The list is illustrative, not a closed enum.
