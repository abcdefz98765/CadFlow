# Missing Information

Ask one focused question only when the answer materially changes topology,
Part count, a real component interface, manufacturing route, load/safety
intent, or acceptance criteria. Use a visible reversible assumption for
low-risk details that can be corrected after geometry is visible. Never choose
a supported template merely to avoid uncertainty. Treat unresolved questions
from a prior proposal as historical context: accepted clarification fields are
resolved and must be incorporated into a fresh proposal rather than reopened.
