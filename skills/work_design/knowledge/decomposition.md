# Part Decomposition

Create only the generated Part Jobs needed for the current Work. Preserve each
Part's purpose, interfaces, dependencies, service access, wiring, motion, and
fastening intent. Do not collapse a functional multi-Part design into one Part
or split a natural single Part to suit current CAD templates. Reference
components provide interface context and are not generated Part Jobs.

Assembly execution is outside the current capability. Record only the design
context needed by Parts; do not create Assembly state.
